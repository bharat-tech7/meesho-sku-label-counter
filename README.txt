MEESHO SKU LABEL COUNTER

USE:
1. Internet ON rakho (PDF.js library CDN se load hoti hai).
2. index.html ko Chrome/Edge me open karo.
3. Meesho Label PDF select karo.
4. "Count SKU Labels" button dabao.
5. Result milega: SKU ID = Total Labels
6. Copy Result ya Download CSV use kar sakte ho.

IMPORTANT:
- App Meesho ke normal text-based shipping label PDF ke liye banaya gaya hai.
- Agar kisi PDF ka layout alag hua aur SKU detect nahi hua, app page number bata dega.
